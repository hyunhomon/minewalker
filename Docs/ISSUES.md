## 이슈 본문 템플릿

```markdown
## 설명
[기능 설명]

## 관련 파일
- 씬: [담당 씬 명시 또는 "없음"]
- 프리팹: [관련 프리팹]
- 스크립트: [관련 스크립트 경로]

## 완료 조건
- [ ] [조건 1]
- [ ] [조건 2]

## 의존성
- #이슈번호 (완료 후 착수 가능)

## 참고
- docs/SCHEMAS.md 참고
```
