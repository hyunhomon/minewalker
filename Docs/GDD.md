## 1. 개요 (Overview)

### 1.1. 게임명 (Game Title)

- **공식 게임명** : MINEWALKER
- **부제** : Every Step Could Be Your Last
- **게임명의 의미** : 지뢰찾기(Minesweeper)에서 파생된 이름. 지뢰 위를 직접 걸어다닌다는 의미로, 기존 지뢰찾기의 클릭 기반 추론을 이동 기반 생존으로 재해석함

### 1.2. 장르 (Genre)

- **주요 장르** : 생존 / 기록 경쟁
- **세부 장르** : 탑다운 2D 도트 / 무한 생성 / 소셜 디덕션 퍼즐

### 1.3. 플랫폼 (Platform)

- **주요 플랫폼** : PC, 모바일 (iOS / Android)
- **개발 엔진** : Unity
- **출시 예정** : PC (Steam) 우선 출시

### 1.4. 타겟 유저 (Target Audience)

- **핵심 타겟층**
  - 연령/성별 : 15~30대, 성별 무관
  - 플레이 스타일 : 짧고 긴장감 있는 기록 경쟁을 즐기는 유저
  - 선호 장르 : Crossy Road, 지뢰찾기, 고양이마리오 팬
  - 플레이 시간 : 1판 3~10분, 언제든 꺼낼 수 있는 캐주얼 세션

### 1.5. 핵심 콘셉트 (Core Concept)

- **엘리베이터 피치** : [생존 기록 경쟁] 게임으로, 플레이어는 [무한히 펼쳐지는 지뢰찾기 맵 위를 직접 걸어다니는 상황]에서 [숫자 힌트를 추론하며 지뢰를 피해 최대한 멀리 전진]하여 [자신의 거리 기록 갱신]을 목표로 합니다.

## 2. 콘셉트 (Concept)

### 2.1. 핵심 재미 (Core Gameplay Loop)

MINEWALKER의 핵심 재미는 **'알고 있다고 생각한 순간 배신당하는 것'** 입니다. 이 재미는 다음 순환 구조를 통해 제공됩니다.

- **행동 (Action)** : 숫자 힌트를 추론하며 안전한 타일로 한 칸씩 전진. 막히면 후퇴해서 다른 루트 탐색
- **보상 (Reward)** : 전진할수록 거리 증가. 최고 기록 갱신 시 성취감
- **동기 부여 (Motivation)** : 기믹이 판단력을 흐리며 점점 어려워짐. "한 번만 더" 심리 유발

### 2.2. 게임 룰

```
기본 룰
├── 탑다운 뷰, 타일 기반 이동
├── 각 타일에는 숫자 힌트 표시 (인접 지뢰 수)
├── 지뢰 타일 밟으면 → 즉사 + 거리 기록 저장
├── 전진 → 거리 증가 / 후퇴 → 거리 감소
└── 맵은 무한 생성 (앞으로 갈수록 새 열 생성)
```

- 지나온 타일은 정보가 공개된 상태로 유지
- 후퇴는 손해지만 정보 수집을 위해 필요한 전략
- 체크포인트 없음. 죽으면 처음부터

### 2.3. 세계관 및 스토리 (World & Story)

스토리 없음. 게임 자체가 스토리. 숫자와 지뢰, 그리고 플레이어의 판단만 존재.

### 2.4. 아트 콘셉트 (Art Concept)

- **아트 스타일** : 16×16 도트 픽셀 아트. 심플하고 밝은 톤
- **색상 팔레트** : 밝은 배경, 명확한 숫자 색상 구분 (1=파랑, 2=초록, 3=빨강...)
- **분위기** : 평상시 밝고 경쾌 / 기믹 발동 시 시각적 변화로 즉각 인지
- **죽음 연출** : 픽셀 파티클 폭발 + 화면 플래시 + "YOU DIED" 텍스트

## 3. 주요 특징 (Key Features)

### 3.1. 무한 맵 생성 알고리즘

플레이어가 전진할수록 새로운 열이 실시간으로 생성됩니다.

- 지뢰 밀도는 거리에 따라 점진적 증가
- 항상 최소 1개의 안전한 경로 보장 (클리어 불가 맵 방지)
- 지뢰 배치 후 숫자 자동 계산 (표준 지뢰찾기 알고리즘)

```
지뢰 밀도 스케일링
├── 0~50칸   : 15%
├── 51~150칸 : 22%
├── 151~300칸: 28%
└── 300칸+   : 33% (고정)
```

### 3.2. 기믹 시스템

시간이 지날수록 현재 레벨이 올라가며, 해당 레벨 이하의 기믹 풀에서 랜덤으로 기믹이 등장합니다.

```
level = floor(distance / 50)
등장 가능 기믹 = difficulty <= level 인 기믹 전체
```

#### 기믹 목록

**정보 왜곡 계열**

| difficulty | 기믹 | 설명 |
|-----------|------|------|
| 1 | 가짜 숫자 | 랜덤 타일 하나 숫자가 틀림. 어딘지 모름 |
| 1 | 숫자 깜빡임 | 숫자가 0.5초마다 깜빡여서 잘 안 읽힘 |
| 2 | 숫자 범위 | "2" 대신 "1~3"으로 표시. 정확한 수 모름 |
| 3 | 인접 숫자 숨김 | 바로 옆 칸 숫자만 안 보임 |
| 4 | 숫자 노이즈 | 숫자 위에 글리치 이펙트. 2인지 3인지 헷갈림 |
| 4 | 숫자 과부하 | 주변 모든 타일 숫자 동시 표시. 정보 마비 |
| 5 | 숫자 섞임 | 주변 숫자들이 랜덤 위치로 섞여 표시. 어느 칸 숫자인지 모름 |
| 5 | 숫자 공유 | 인접 두 타일 숫자 합산 표시. 분리 불가 |

**시야 계열**

| difficulty | 기믹 | 설명 |
|-----------|------|------|
| 1 | 안개 | 시야 2칸 제한. 멀리 못 봄 |
| 2 | 블랙아웃 | 3턴마다 1턴 전체 암전 |
| 3 | 시야 역전 | 가까운 건 안 보이고 먼 것만 보임 |
| 4 | 거울 맵 | 시야가 좌우 반전되어 표시 |

**심리 계열**

| difficulty | 기믹 | 설명 |
|-----------|------|------|
| 2 | 타일 색 반전 | 안전=빨강, 지뢰=초록으로 표시. 뇌가 거부함 |
| 3 | 페이크 지뢰 | 지뢰처럼 생겼는데 안전. 진짜도 섞여 있음 |
| 5 | 카운트다운 타일 | 밟으면 3초 후 지뢰로 변함 |

### 3.3. 거리 기록 시스템

```
현재 거리     실시간 표시
최고 기록     로컬 저장
죽었을 때     "최고기록까지 N칸" 표시 → 리플레이 유도
```

- 최고기록 3칸 앞에서 죽는 순간이 핵심 빡침 포인트
- 추후 글로벌 리더보드 추가 가능

## 4. 경쟁 분석 (Competitive Analysis)

### 4.1. 경쟁작 분석

| 경쟁작 | 강점 | 약점 |
|--------|------|------|
| Minesweeper | 전 세계 누구나 아는 룰, 진입장벽 없음 | 이동/액션 요소 없음, 정적임 |
| Crossy Road | 무한 진행 + 거리 기록, 중독성 높음 | 추론 요소 없음, 단순 반사신경 |
| 고양이마리오 | 속임수 레벨 디자인, 빡침 + 재도전 욕구 | 레벨 한정, 무한 플레이 불가 |

### 4.2. 차별점 (Our Unique Selling Points)

- **기존 지뢰찾기를 아는 사람이라면 룰 설명 0초** — "지뢰찾기인데 직접 걷는다"
- **무한 생성으로 레벨 디자인 공수 없음** — 알고리즘이 매판 새로운 맵 생성
- **기믹 시스템으로 단순 반복 방지** — 같은 판이 없음, 예측 불가
- **후퇴 전략** — Crossy Road와 달리 되돌아가는 판단도 중요. 깊이 있는 의사결정

## 5. 개발 계획 (Development Plan)

### 5.1. 팀 구성

| 역할 | 담당 |
|------|------|
| 리드 개발 | 맵 생성 알고리즘, 기믹 시스템, 난이도 스케일링 |
| 개발 A | 캐릭터 이동 (탑다운 4방향, 타일 기반) |
| 개발 B | UI (거리 카운터, 기록, 죽음 연출) |
| 아트 A | 도트 아트 (캐릭터, 타일셋, 파티클) |
| 사운드 A | 사운드 + BGM |

### 5.2. 8주 타임라인

```
1주    타일 시스템, 이동, 충돌, 지뢰 배치 알고리즘
2주    숫자 계산, 거리 기록, 죽음 연출
3~4주  기믹 시스템 전체 구현 (15개)
5주    난이도 스케일링 + 팀원 모듈 통합
6주    플레이테스트 + 밸런싱
7주    폴리싱 (이펙트, 사운드, UI)
8주    버그픽스 + 데모 빌드
```
