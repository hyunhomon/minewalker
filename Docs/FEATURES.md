# Features

GDD 기반 기능 단위 분리. GitHub 이슈 생성 시 참고용.

---

## Phase 1: 코어 (1~2주)

### [Feat] 타일 시스템

- [ ] Unity Tilemap 기반 그리드 생성
- [ ] 타일 상태 관리 (Hidden / Revealed / Exploded)
- [ ] 타일 클릭/이동 시 공개 처리

### [Feat] 지뢰 배치 알고리즘

- [ ] 기본 지뢰 랜덤 배치
- [ ] 인접 지뢰 수 계산 (표준 지뢰찾기 알고리즘)
- [ ] 안전 경로 보장 로직

### [Feat] 무한 맵 생성

- [ ] 플레이어 전진 시 새 열 생성
- [ ] 지뢰 밀도 스케일링 (15% → 22% → 28% → 33%)
- [ ] 뒤쪽 열 해제 (메모리 관리)

### [Feat] 플레이어 이동

- [ ] 탑다운 4방향 타일 기반 이동
- [ ] 전진/후퇴 판정 (거리 증가/감소)
- [ ] 지뢰 밟으면 즉사 처리

### [Feat] 거리 기록 시스템

- [ ] 현재 거리 실시간 추적
- [ ] 최고 기록 로컬 저장 (PlayerPrefs)
- [ ] 사망 시 "최고기록까지 N칸" 표시

### [Feat] 사망 연출

- [ ] 픽셀 파티클 폭발
- [ ] 화면 플래시
- [ ] "YOU DIED" 텍스트 + 거리 표시

## Phase 2: 기믹 시스템 (3~4주)

### [Feat] 기믹 매니저

- [ ] 레벨 계산: `level = floor(distance / 50)`
- [ ] 레벨 기반 기믹 풀링
- [ ] 기믹 활성화/해제 라이프사이클

## Phase 3: 통합 + UI (5주)

### [Feat] 난이도 스케일링 통합

- [ ] 거리별 지뢰 밀도 + 기믹 레벨 연동
- [ ] 밸런스 테스트용 디버그 UI

### [Feat] UI 시스템

- [ ] HUD: 현재 거리, 최고 기록, 활성 기믹 표시
- [ ] 사망 화면: 기록 요약 + 재시작 버튼
- [ ] 메인 메뉴: 시작, 기록 확인

### [Art] 도트 아트

- [ ] 캐릭터 스프라이트 (idle, walk 4방향)
- [ ] 타일셋 (숨김, 공개, 숫자 1~8, 지뢰, 폭발)
- [ ] 기믹 이펙트 스프라이트
- [ ] UI 요소

### [Sound] 사운드

- [ ] BGM 메인 테마
- [ ] SFX: 이동, 타일 공개, 지뢰 폭발, 사망
- [ ] 기믹별 사운드 이펙트

---

- [ ] 기믹 등장 빈도/지속시간 조정

- [ ] 파티클 이펙트 보강

### [Infra] 빌드

- [ ] PC (Steam) 빌드 설정
- [ ] 빌드 테스트
