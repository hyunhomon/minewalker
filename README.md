# MINEWALKER

> Every Step Could Be Your Last

지뢰찾기 맵 위를 직접 걸어다니며 숫자 힌트를 추론하고, 지뢰를 피해 최대한 멀리 전진하는 생존 기록 경쟁 게임.

## Tech Stack

- **Engine**: Unity 6.4 (URP 2D)
- **Language**: C#
- **Art**: Aseprite (16x16 pixel art)
- **VCS**: Git + Git LFS

## Getting Started

### 요구 사항

- Unity 6.4.0f1
- Git LFS

### 클론

```bash
git clone <repo-url>
git lfs install
```

Unity Hub에서 프로젝트 열기.
